# SPADE-Calib

**Sparse Point-cloud Accumulation and Depth-Enhanced LiDAR–Camera Calibration**

Research repository under initial setup. The project investigates targetless LiDAR–camera extrinsic calibration using accumulated sparse LiDAR geometry, camera depth and plane correspondences.

> Status: work in progress. The existing experimental scripts are being inventoried and reviewed before publication. No end-to-end reproducible pipeline has been released yet.

See the repository's pull requests for the initial package structure and documentation.
